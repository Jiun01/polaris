# Contributing

The code is BUSL-1.1 — free to read, modify, and self-host for personal or
internal use; offering it (or derivatives) as a hosted, white-labeled, or
resold service is not permitted. See [LICENSE](LICENSE) for the exact
terms; it converts to Apache-2.0 on 2030-11-04.

- **Pull requests are not accepted.** The code is maintained privately.
- **Issues** may be opened for questions or notable defects, with no
  commitment to respond or merge fixes.
- **Forks and derivative works are welcome** as long as they keep the
  copyright notice and credit the original project
  ("Polaris by Jiun, https://getpolaris.my"). The upstream forks under
  `forks/` carry their own licenses (MIT / GPL-3.0) and welcome contributions
  under those terms.
